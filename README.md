# 🎭 音響パッド

学校祭の演劇などで使う、効果音・BGM の再生アプリです。ブラウザで開くだけで使えます（Chromebook 対応）。

**▶ 使う：https://choppermoon1623-tech.github.io/onkyo-pad/**

- MP3・WAV などの音を入れて、クリックかキーボードで鳴らします。パッドはキーボードと同じ並び。
- 音ごとに、名前・キー・色・音量・使う範囲（〇秒〜〇秒）・ループ・フェード・もう一度押したときの動きを設定できます。
- Esc ですべて停止、Space で 2 秒かけて消音。
- 「✏️ 編集／🎬 本番」の切り替えで、本番中のうっかり変更を防ぎます。
- 音と設定はその端末のブラウザの中に保存されます（外部には送信しません）。「💾 バックアップ」で 1 つのファイルにまとめ、別の端末へ移せます。

登録不要・外部ライブラリなしの 1 ファイル（index.html）です。
